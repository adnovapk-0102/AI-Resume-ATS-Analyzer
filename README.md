# 🚀 AI-Powered Resume & Career Intelligence Suite

An enterprise-grade Applicant Tracking System (ATS) simulator, resume optimizer, and career coaching tool built with Python, Streamlit, and Google Gemini AI.

## 🌟 Key Features
- **Core Diagnostics:** Deep analysis of ATS compatibility, keyword matching, and formatting safety.
- **AI Resume Builder:** Automatically generates a fully rewritten, high-impact resume in Markdown format.
- **Smart Optimization:** Compares weak bullet points with AI-generated, metric-driven alternatives.
- **Career Suite:** Generates tailored cover letters, cold email templates for networking, and salary negotiation scripts.
- **Interview Prep & Skill Gaps:** Provides mock interview questions and mini-project recommendations to cover missing skills.
- **Regional Localization:** Adjusts resume feedback based on US/Canada, Europe, Gulf, or Asian corporate standards.
